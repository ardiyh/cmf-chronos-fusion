# G4 protocol: more targets, all eligible origins and day-ahead (D6)

Frozen 16 November 2026 before any G4 inference. Common settings, GPU
operation (160 W, no fixed delay, cooldown, guard) and statistics are those of
`GPU_G1G2_PROTOCOL_20261116.md`. Runs use `experiments/run_target_variants.py`,
a thin wrapper that only swaps the target channel or enables Chronos-T5's own
autoregressive rollout past 64 steps; the controls runner is unchanged.

"CMF" below is the Table 5 validation winner with retained default
hyperparameters, mode `target_units`. When that winner is identity (ECL H48,
ETTm1 H48), CMF-Select keeps identity and the case has no contrast.

## G4a: all eligible test origins, primary target

- Split `test`, `--all-eligible` (stride H, every complete origin), H24 and H48
  run separately with that horizon's winner: identity, CMF, same-seed replay.
- 4,142 origin–horizon pairs. ETTh1/ETTh2 have no cap effect (eligible equals the
  capped grid), so their values come from G2 with identical seeds and origins.
- Family: CMF minus identity, median-point MASE, over the 14 cases with a
  non-identity winner, Holm14 and block Holm14.

## G4b: four more targets per dataset

- Four extra targets per dataset, drawn once without replacement with
  `numpy.random.default_rng([2026, zlib.crc32(dataset)])` from the non-primary
  channels whose training-split std is positive:
  ETTh1 HULL, MUFL, MULL, LUFL; ETTh2 HUFL, HULL, MULL, LULL;
  ETTm1 HUFL, HULL, MUFL, MULL; ETTm2 MUFL, MULL, LUFL, LULL;
  ECL MT_100, MT_185, MT_194, MT_207; OPSD FR, NL, CH, DK;
  SDWPF turbine_16, turbine_39, turbine_43, turbine_98;
  Solar-AL solar_2, solar_32, solar_45, solar_127.
- Every other stored channel, including the original target, is a covariate.
- H24 on the capped test grid (`--max-origins 150`), identity, CMF transferred
  from the dataset's H24 winner (no per-target reselection), same-seed replay.
  4,760 origin–target pairs.
- Family: CMF minus identity, median-point MASE, 32 contrasts, Holm32 and block
  Holm32. Transfer tests whether the dataset's selected configuration generalizes
  across targets; it is not a per-target tuned CMF. The four ETT datasets share
  one source and are reported as one source group as well.

## G4c: day-ahead horizon for subhourly data

- One day ahead: ETTm1/ETTm2 H96 (15 min), SDWPF/Solar-AL H144 (10 min); the
  hourly datasets' H24 is already day-ahead. Capped test grid with stride H:
  145, 145, 48 and 73 origins.
- Chronos-T5 forecasts 64 steps per pass; `--rollout` uses the pipeline's own
  autoregressive continuation. Identity, CMF from the H48 winner, replay.
- Family: CMF minus identity for ETTm2, SDWPF and Solar-AL (ETTm1 keeps
  identity), Holm3. Few origins at H144 limit block resolution; non-rejection is
  not equivalence.
- Positional horizons: the timestamp-unit/gap caveats in
  `reproducibility/datasets.md` still apply; no gap repair is attempted here.

## Budget and order

About 26,000 calls after G1, G3 and G2: G4a ±10,700, G4b 14,280, G4c ±1,100
(rollout passes are slower). All cases are reported whatever the direction.
